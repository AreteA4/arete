For generated React consumers, install `@usearete/react @usearete/sdk zod`. Do not install `zustand` separately. Hosted ORE browser apps must pass `VITE_ARETE_PUBLISHABLE_KEY` to `AreteProvider` as `auth={{ publishableKey }}`; read-only viewing does not require a wallet, but it does require authentication.
