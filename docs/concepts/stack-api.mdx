# Stack API (Legacy Location)

The hand-authored `defineStack` and view-factory API previously documented here has been superseded by generated stack definitions.

Use the maintained references instead:

- [React SDK](/sdks/react/) — `AreteProvider`, `useArete`, keyed state views, connection status, and mutations
- [TypeScript SDK](/sdks/typescript/) — sessions, generated stacks, streaming views, and one-shot reads
- [Schema Validation](/sdks/validation/) — generated and caller-supplied schemas
- [Connect to a Stack](/using-stacks/connect/) — end-to-end hosted ORE setup

Generated TypeScript entity properties use camelCase. Rust DSL paths, raw IDL inputs, WebSocket wire fields, and filter dot paths retain their declared snake_case spelling.
