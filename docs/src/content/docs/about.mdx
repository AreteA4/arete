Arete is a platform for building and running protocols on Solana. Compose
programs into typed steps with permissions and lifecycle, develop in a
persistent cloud mainnet fork, and connect applications and agents through
generated clients. Program SDKs and live views support those protocols and
remain useful independently.

This website, [docs.arete.run](https://docs.arete.run/), is the documentation
and developer surface for that platform. It is not a consumer app and it is
not a generic Solana RPC. The marketing homepage lives at
[arete.run](https://arete.run/?utm_source=docs&utm_medium=referral&utm_campaign=docs&utm_content=about_home).

## What Arete is for

- Define protocols with steps, guards, roles, instance and participant state,
  reactions, metadata, and events.
- Develop in a cloud mainnet fork with local wallets, live activity,
  checkpoints, scenarios, and replay.
- Integrate published protocols from apps and agents, with local signing and
  explicit execution outcomes.
- Discover programs and stacks from a product question, without guessing
  program IDs, account layouts, or endpoints.
- Explore live views through MCP or `a4 stream`.
- Generate TypeScript, React, Rust, or Python clients bound to an exact
  catalog descriptor.
- Read typed program accounts and construct instructions through generated
  SDKs. Signing and submission stay under user authority.
- Author a custom stack in the Rust DSL only when the catalog does not already
  expose the required read model.

## What is open source

Most of Arete is open source under Apache-2.0 or MIT, and the hosted service
adds discovery, review, receipts, cloud dev environments and operations. See
[Open source and hosted Arete](/getting-started/open-source-and-hosted/).

## Who maintains it

The open-source repository is
[AreteA4/arete](https://github.com/AreteA4/arete). Documentation lives in the
`docs/` directory of that repository and deploys to this origin. Product
skills live in [AreteA4/skills](https://github.com/AreteA4/skills).
