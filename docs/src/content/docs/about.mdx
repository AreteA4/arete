Arete gives AI agents sandboxes on Solana: a funded wallet the agent can use
but never holds the key to, inside rules its owner signs. The rules decide
which programs the agent may act on and which it may read; program reads and
live views are the sandbox's read side. Protocols, automations, cloud dev
environments and SDKs are in private beta.

This website, [docs.arete.run](https://docs.arete.run/), is the documentation
and developer surface for that platform. It is not a consumer app and it is
not a generic Solana RPC. The marketing homepage lives at
[arete.run](https://arete.run/?utm_source=docs&utm_medium=referral&utm_campaign=docs&utm_content=about_home).

## What Arete is for

- Give an agent a funded wallet without giving it a key.
- Limit the agent to the programs, instructions, spend limits and
  destinations you sign.
- Scope what the agent can read to the same programs.
- Record every action an agent asks for, refusals included, with decoded
  instructions, events and balance changes.
- Read typed program accounts and live views from the CLI, MCP or generated
  SDKs.
- In private beta: compose programs into protocols, automate steps for users,
  develop in cloud mainnet forks, and author custom live data.

## What is open source

Most of Arete is open source under Apache-2.0 or MIT, and the hosted service
adds discovery, review, receipts, cloud dev environments and operations. See
[Open source and hosted Arete](/getting-started/open-source-and-hosted/).

## Who maintains it

The open-source repository is
[AreteA4/arete](https://github.com/AreteA4/arete). Documentation lives in the
`docs/` directory of that repository and deploys to this origin. Product
skills live in [AreteA4/skills](https://github.com/AreteA4/skills).
