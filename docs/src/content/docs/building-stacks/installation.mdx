Set up your development environment for building Arete stacks.

:::tip[Just want to use an existing stack?]
If you're consuming data from a deployed stack, see [Using Stacks → Installation](/using-stacks/installation) instead.
:::

---

## Prerequisites

- **Rust** 1.70+ ([install via rustup](https://rustup.rs/))
- A code editor with Rust support (VS Code + rust-analyzer recommended)

---

## CLI

The Arete CLI (`a4`) handles project initialization, deployment, and SDK generation. Install the prebuilt binary (Rust is needed to build stacks, but not to install the CLI):

```bash
curl -fsSL https://arete.run/install.sh | sh        # macOS / Linux
irm https://arete.run/install.ps1 | iex             # Windows PowerShell
npx @usearete/a4 install                            # if you prefer npm
```

Verify the installation:

```bash
a4 --version
a4 doctor --json
```

:::note[PATH configuration]
The installer puts `a4` in `~/.local/bin` and adds it to your shell profile. If `a4` is not found in an already-open terminal, run `export PATH="$HOME/.local/bin:$PATH"` or use the absolute path the installer printed as `A4_BIN=`.
:::

Update later with `a4 self update`. Full installer options: [CLI Command Reference → Installation](/cli/commands/#installation).

### Building from source

Only if you need an unreleased build:

```bash
cargo install a4-cli
```

A Cargo-built `a4` cannot use `a4 self update`; rebuild with `cargo install a4-cli --force` instead.

## Rust Dependencies

Add the Arete crate to your stack project's `Cargo.toml`:

```toml
[dependencies]
arete = "{{VERSION}}"
serde = { version = "1.0", features = ["derive"] }
```

This gives you access to:

- `#[arete]` — The main macro for defining stacks
- `#[entity]`, `#[map]`, `#[aggregate]` — Field-level attributes
- `Stream` derive macro — Generates streaming infrastructure

---

## Project Initialization

Create a new stack project:

```bash
cargo new my-stack --lib
cd my-stack
```

Initialize Arete configuration:

```bash
a4 init
```

This creates `arete.toml` and a `.arete/` directory for generated stack files.

**arete.toml:**

```toml
[project]
name = "my-stack"

[sdk]
output_dir = "./generated"
```

Validate your setup:

```bash
a4 config validate
```

## Troubleshooting

| Issue                   | Solution                                        |
| ----------------------- | ----------------------------------------------- |
| `a4: command not found` | Add `~/.local/bin` to your PATH                 |
| `cargo build` fails     | Ensure `arete = "{{VERSION}}"` is in Cargo.toml |
| `a4 init` fails         | Check you're in a valid Cargo project           |
