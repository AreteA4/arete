Beyond sandboxes, Arete has a set of tools for building Solana products. They
are in private beta: the docs are public, and access is enabled per account.

| Area                                                      | What it does                                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [Protocols](/concepts/protocols/)                         | Compose Solana programs into workflows with typed steps, guards, roles and lifecycle |
| [Automations](/automations/overview/)                     | Run protocol steps for users from a backend, within limits each user signed          |
| [Cloud dev environments](/cli/local-development/)         | Develop against a persistent mainnet fork with checkpoints, time control and replay  |
| [Integrating protocols](/integrating-protocols/overview/) | Install a published protocol's generated client into an app or agent                 |
| [Deploy and trust](/deploying-protocols/overview/)        | Deploy protocols, with handler review and receipts                                   |
| [Squads](/building-protocols/squads/)                     | Bring your own Squads multisig to a protocol deployment                              |
| [Custom live data](/building-stacks/workflow/)            | Author stacks of live views from program IDLs in the Rust DSL                        |
| [SDKs](/sdks/typescript/)                                 | Generated TypeScript, React, Rust and Python clients                                 |
| [Self-hosted stack server](/a4-server/overview/)          | Run the open-source server for live views yourself                                   |

[Program reads](/using-programs/program-reads/) and
[live views](/using-stacks/connect/) are documented alongside sandboxes, as
the sandbox's [read side](/sandboxes/read-scope/).

To ask for access, [get in touch](/contact/).
